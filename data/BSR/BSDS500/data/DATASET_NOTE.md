Source
-
The main dataset to test the edge-detection research is taken from
The Berkeley Segmentation Dataset and Benchmark.

Description
-
Dataset contains 500 images and corresponding human annotations.
The first annotator's Boundaries map was extracted from each MATLAB (.mat) annotation file and converted into a PNG image.
Original images and reference boundaries are matched by filename.

Purpose
-
Using the images to study edge-detection research and the evaluation of Sobel, Prewitt, Laplacian, and Canny edge detectors. 

Citation
- 
- Contour Detection and Hierarchical Image Segmentation
P. Arbelaez, M. Maire, C. Fowlkes and J. Malik.
IEEE TPAMI, Vol. 33, No. 5, pp. 898-916, May 2011.
